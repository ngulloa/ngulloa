# Recursos del portafolio

`assets/perfil/foto_perfil.jpeg` es la ilustración de retrato suministrada para Inicio. La fotografía anterior permanece como archivo local preexistente, pero ya no se muestra. `assets/proyectos/lif/` y `assets/proyectos/precalculo/` contienen capturas de los sitios reales. `assets/proyectos/metodos-numericos/` contiene gráficos de una ejecución documentada de los programas originales; las guías PDF están en `downloads/metodos-numericos/`.

`assets/proyectos/kerr/` contiene imágenes extraídas del informe original y `downloads/kerr/efecto-kerr-informe.pdf` conserva el PDF entregado sin modificación. La ficha Kerr documenta la procedencia y las limitaciones de interpretación. `assets/profile/avatar-placeholder.svg` es un respaldo neutral que no se muestra actualmente.
